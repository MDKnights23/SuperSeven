# My Python Project

This is a starter Python project created in the current workspace.

## Setup

```bash
python -m venv .venv
source .venv/bin/activate   # macOS/Linux
.\.venv\Scripts\activate    # Windows PowerShell
pip install -e .
```

## Run the app

```bash
python -m my_python_project.main
```

## Test

```bash
pytest
```
